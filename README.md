# حصين · Haseen — Landing Page

اللاندنج بيج الرسمية لتطبيق **حصين**، تطبيق الحماية الأسرية للسعودية.

**التقنيات:** Next.js 15 · React 19 · TypeScript · Tailwind CSS v4 · Framer Motion · Lucide Icons. والنشر على Vercel من GitHub.

## التشغيل

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # نسخة الإنتاج
```

## وين تعدّل؟

| الملف | شو فيه |
|---|---|
| `src/content/ar.ts` | **كل نصوص الصفحة**. تعدّل الكلام من هون بس. |
| `src/config/site.ts` | روابط App Store و Google Play، والدومين، والإيميل. |
| `src/styles/globals.css` | ألوان الهوية، والخطوط، والزخارف (النقش، القوس النجدي، الذهبي اللامع). |
| `src/components/brand/Logo.tsx` | الشعار الرسمي كـ SVG (الدرع + الاسم). |
| `src/sections/*` | أقسام الصفحة، كل قسم بملف. |

## الهوية (من دليل الهوية البصرية)

- **الألوان:** بنفسجي حصين `#4F008C` · ليل الحصن `#2E0052` · ذهبي فاتح `#FCA503` · لافندر `#F3ECF9` · حبر `#1C1426`.
- **الخطوط:** El Messiri للعناوين، و IBM Plex Sans Arabic للنصوص، بنفس أحجام موقع منيب.
- **الألوان مقفولة:** `--color-*: initial` بيلغي ألوان Tailwind الافتراضية، فأي لون برّا الهوية ما رح يشتغل.

## الأقسام

1. **الهيرو:** جوال فيه لوحة ولي الأمر، وإشعارات عايمة، وحركة parallax مع الماوس.
2. **كذا تبدأ القصة:** محادثة لعبة بتنكتب قدامك، وبعدين بيطلع تنبيه حصين.
3. **خمس مخاطر:** تابات تفاعلية مع مشهد مسح ورصد.
4. **رفيق التربية:** مهام بتنعلّم، وطلب تحميل بتوافق عليه أو بترفضه، ومتابعة مدرسية، وحجب بمفاتيح تشغيل.
5. **٣ خطوات:** شارات على شكل قوس نجدي.
6. **سعودي الفهم.**
7. **الخصوصية.**
8. **الأسئلة الشائعة.**
9. **الدعوة الأخيرة.**
